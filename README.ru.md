# Placitum logger

[English](README.md) · Русский

Журнал Placitum: читает поток аудита с шины, раскладывает сообщения по таблицам и пакетами пишет в
ClickHouse. Рядом работает поиск по тому, что записано.

Он вне пути запроса: сбой ClickHouse не двигает дедлайн проверки запроса. JetStream — буфер, логгер —
durable consumer.

```
waf.audit.request.<узел>     ─┐
waf.audit.inspector.<имя>    ─┴─►  waf-logger  ─ пакетом ─►  waf.audit, waf.audit_finding
                                        │
waf.log.<писатель>           ────►      │      ─ пакетом ─►  waf.log
  (агенты узлов, процессы установки)    │
                                        └─ ack JetStream после вставки

                                   waf-search  ──►  /api/audit, /api/findings, /api/logs
```

В образе два бинаря. `waf-logger` читает шину и накатывает схему ClickHouse при старте;
`waf-search` отдаёт HTTP API поиска для панели на `:8091`. Что запускать, решает команда контейнера;
по умолчанию — логгер.

## Что хранится

| Таблица | Строка на | Срок |
| --- | --- | --- |
| `waf.audit` | фазу запроса или кадр WebSocket: соединение, маршрут, вердикт, счёт, итоги инспекторов, превью, ключи архива | 90 дней |
| `waf.audit_finding` | находку инспектора: правило, код, серьёзность, улика, сообщение и метки | 90 дней |
| `waf.log` | строку журнала процесса или nginx | 14 дней |

Записи одного запроса связываются на чтении по `node` и `ray`: реплики пишут независимо и друг друга
не ждут. Словари `waf.geo_country` и `waf.geo_asn` загружает сам ClickHouse из PostgreSQL контроллера,
на них работают фильтры поиска по стране и системе.

## API поиска

| Ручка | Что отвечает |
| --- | --- |
| `GET /api/audit` | запросы по фильтру |
| `GET /api/audit/groups` | запросы, сгруппированные для списка инцидентов |
| `GET /api/audit/{node}/{ray}` | один запрос с его фазами |
| `GET /api/audit/{node}/{ray}/inspectors`, `…/findings` | итоги инспекторов и находки запроса |
| `GET /api/audit/{node}/{ray}/headers`, `…/args`, `…/body` | содержимое из архива S3 |
| `GET /api/findings` | находки по фильтру, в том числе по `tag` |
| `GET /api/logs`, `GET /api/logs/facets` | строки журнала и их разрезы |
| `GET /healthz` | жив ли процесс |

В поиск ходит панель; `:8091` наружу не выставляют.

## Схема

`waf-logger` накатывает `schema/` при старте: по одному оператору на файл, применённые файлы
отмечаются в `waf.schema_migrations`, а замок не даёт стартующим разом репликам подраться. Схема
создаётся на пустой базе; миграций обновления нет.

Что нужно рядом, настройки и проверка — в [INSTALL.ru.md](INSTALL.ru.md).
